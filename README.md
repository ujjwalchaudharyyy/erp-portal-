# College ERP Portal

A modern, responsive College ERP Portal web application for students and faculty.

## Features
- **Student & Faculty Login**: Secure portal authentication with modern UI.
- **Interactive Dashboard**:
  - Attendance overview and subject-wise breakdown
  - Timetable and schedule tracker
  - Fees status and transaction history
  - Internal marks and grade reports
  - Announcements, circulars, and notices
- **Clean Responsive Design**: Designed with modern CSS and fluid layouts for desktop and mobile devices.

## Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla ES6+)
- **Deployment**: Vercel ready (`vercel.json`)

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/ujjwalchaudharyyy/erp-portal-.git
   ```
2. Open `index.html` in your browser or run with a local server (e.g. Live Server).
